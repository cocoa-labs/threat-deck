# Security

Report a suspected vulnerability through [GitHub private vulnerability reporting](https://github.com/cocoa-labs/threat-deck/security/advisories/new). Include affected version, reproduction steps, expected impact and a minimal synthetic example. Do not include live credentials or customer data. Please avoid public disclosure while a report is being investigated. This project does not promise a response or remediation deadline.

The currently maintained release line is 0.1.x. Keep the application and its dependencies updated. The application is a single-tenant intelligence tool, not an intrusion-prevention system or an authoritative risk assessment. Operators must verify source data and AI recommendations before acting.

See [security architecture](docs/SECURITY-ARCHITECTURE.md) and [deployment](DEPLOY.md) for trust boundaries, required configuration and operational limitations.
